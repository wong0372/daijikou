DAIJIKOU PORTFOLIO — WORKING HOMEPAGE PROTOTYPE

How to preview:
1. Open index.html in Chrome, Safari, Edge, or Firefox.
2. Keep the assets folder, styles.css, and script.js in the same folder.

What is included:
- Responsive desktop and mobile homepage
- Hero section
- Selected works
- Collections
- Editable artist introduction placeholder
- Collaboration section
- Contact section
- Scroll reveal and hover animation

Important:
This is a coded working prototype, not yet a native Framer project. It provides the real layout and interaction direction for recreating the site in Framer. The artist biography, email, Instagram, artwork titles, dates, and media details still need confirmation.
